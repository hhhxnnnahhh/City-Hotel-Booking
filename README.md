# City Hotel Booking Demand: Regression, Classification, and Clustering

## Project Overview

This project analyzes hotel booking data from a city hotel to explore booking patterns and build machine learning models for different prediction and analysis tasks.

The project covers three main machine learning tasks:

- **Regression:** Predicting the Average Daily Rate (ADR).
- **Classification:** Predicting whether a hotel booking will be canceled.
- **Clustering:** Discovering groups of similar hotel bookings.

Additional techniques include dimensionality reduction, model evaluation, and hyperparameter tuning.

## Dataset

- **Dataset:** `H2.csv`
- **Source:** [Hotel Booking Demand Dataset](https://raw.githubusercontent.com/afaq-ahmad/Hotel-booking-demand-Case-Study/master/H2.csv)
- **Hotel type:** City Hotel

The dataset contains booking information and features that will be explored during data preparation and analysis.
